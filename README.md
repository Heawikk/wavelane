# Wavelane

Личный стриминговый сервис музыки с бесконечным персональным радио —
**«Моя волна»**.

Вы заливаете свою фонотеку на сервер; он разбирает теги, достаёт обложки,
анализирует сам звук и дальше подбирает музыку под ваш вкус, настроение и
время — поток, который реагирует на каждый лайк, дизлайк и пропуск.

```
┌────────────────────┐        HTTP/JSON + Range        ┌──────────────────────┐
│  Qt 6 / QML клиент │ ◄─────────────────────────────► │  FastAPI сервер      │
│                    │                                 │                      │
│  • «Моя волна»     │   GET  /wave/next               │  • каталог           │
│  • плеер (FFmpeg)  │   POST /wave/feedback           │  • ingest + DSP      │
│  • поиск, коллекция│   GET  /stream/{id}  (Range)    │  • движок волны      │
│  • загрузка файлов │   POST /library/plays           │  • стриминг          │
└────────────────────┘                                 └──────────┬───────────┘
                                                                  │
                                                       SQLite / PostgreSQL
                                                       + файловое хранилище
```

## Статус

| Компонент | Состояние |
|---|---|
| Сервер (FastAPI) | Работает. 67 операций API, 153 теста проходят |
| Движок «Моя волна» | Работает: учится на лайках и прослушивании, реагирует на дизлайки |
| Анализ аудио (DSP) | Работает: темп, тональность, энергия, яркость, динамика |
| Клиент (Qt 6 / QML) | Собирается и играет: вход, волна, поиск, коллекция, загрузка |
| Android / Linux | Не начато. Ядро клиента на C++/QML переносимо |

## Быстрый старт

На Windows всё уже настроено — достаточно двух скриптов из корня проекта:

```bat
run-server.bat          :: сервер на http://127.0.0.1:8000
run-client.bat          :: приложение
```

Сервер должен работать до запуска клиента. Закрыть сервер — `Ctrl+C` в его окне.

### Сервер подробнее

```bash
cd server
python -m venv ../.venv
../.venv/Scripts/python.exe -m pip install -e ".[dev]"   # Linux: ../.venv/bin/python

cp .env.example .env        # обязательно смените WAVELANE_SECRET_KEY
../.venv/Scripts/python.exe -m uvicorn wavelane.main:app --port 8000
```

`run-server.bat` делает то же и пропускает через себя любые опции uvicorn:

```bat
run-server.bat --reload               :: перезапуск при изменении кода
run-server.bat --port 9000
run-server.bat --host 0.0.0.0         :: доступ с других устройств в сети
```

Документация API откроется на <http://127.0.0.1:8000/docs>.

**Первый зарегистрированный аккаунт становится администратором** — создайте его
сразу, через клиент или через `POST /api/v1/auth/register`.

### Сервер в открытом доступе

По умолчанию сервер слушает только `127.0.0.1`. Перед тем как открывать его в
интернет, пройдитесь по списку.

1. **HTTPS обязателен.** Сервер сам TLS не делает, а пароль и токены без него
   идут открытым текстом. Поставьте перед ним обратный прокси и наружу открывайте
   только его порт, а `8000` оставьте закрытым. Пример для Caddy
   (сертификат Let's Encrypt получается сам):

   ```
   music.example.com {
       reverse_proxy 127.0.0.1:8000
   }
   ```

   Подойдёт и Cloudflare Tunnel (`cloudflared tunnel --url http://127.0.0.1:8000`):
   порты на роутере тогда вообще не нужны. Если прокси стоит на другом компьютере,
   запустите сервер с `--forwarded-allow-ips <адрес прокси>`, иначе в логах и в
   ограничениях попыток будет адрес самого прокси.
2. **Режим production** в `server\.env`. Сервер не запустится, пока что-то из
   этого не так:

   ```
   WAVELANE_ENVIRONMENT=production
   WAVELANE_DEBUG=false
   WAVELANE_SECRET_KEY=<длинная случайная строка, 32+ символов>
   WAVELANE_CORS_ORIGINS=[]
   ```

   В этом режиме закрыты страницы `/docs` и `/openapi.json`. Сгенерировать ключ:
   `python -c "import secrets; print(secrets.token_urlsafe(48))"`. Смена ключа
   выбрасывает всех из аккаунтов.
3. **Регистрация.** С `WAVELANE_ALLOW_REGISTRATION=true` аккаунт может создать любой
   человек из интернета. Пусть друзья зарегистрируются, а потом поставьте `false` и
   перезапустите сервер. Первый созданный аккаунт всегда администратор, поэтому
   на пустой базе регистрацию открытой не оставляйте.
4. **Пароль администратора** — длинный, лучше случайный (12+ символов). Он единственное,
   что защищает загрузку файлов и импорт папок.
5. **Файлы.** `server\.env`, `wavelane.db` и `storage\` не должны попадать в
   репозиторий и в общие папки; делайте их резервную копию.

Что сервер делает сам: ни каталог, ни поиск, ни плейлисты, ни тексты не отдаются
без входа; попытки входа ограничены (6 неудач для пары адрес + аккаунт за 15 минут,
30 с одного адреса, 5 регистраций в час с одного адреса, ответ `429`); пароли
хешируются не в основном потоке, поэтому поток запросов на вход не останавливает
остальных; слишком большие JSON-запросы отклоняются; токены воспроизведения
скрыты в журнале доступа; в ответах стоят `nosniff` и `X-Frame-Options`. Обложки
и аватарки открыты по ссылке (имя файла — его хеш), потому что их забирает Discord.

Чего нет: двухфакторной защиты и учёта попыток между перезапусками (счётчики в
памяти). Зависимости проверяйте командой `pip-audit`.

```bash
cd server

```

### Добавление музыки

Добавлять музыку могут **только администраторы** (первый зарегистрированный
аккаунт — администратор). Остальные только слушают.

**Целая папка.** В клиенте: *Коллекция → Импорт папки*. Сервер разбирает теги,
достаёт обложки и анализирует звук в фоне: идёт полоса прогресса, импорт можно
остановить, а клиент подхватит уже идущий импорт после перезапуска. Папки
вложенные, файлы разбираются в нескольких потоках (число задаёт
`WAVELANE_IMPORT_WORKERS`, по умолчанию выбирается само, до 4). Одновременно идёт
один импорт. То же через API:

```bash
curl -X POST http://127.0.0.1:8000/api/v1/admin/imports   -H "Authorization: Bearer <access_token>" -H "Content-Type: application/json"   -d '{"path":"E:/Wavelane/demo_music"}'
curl http://127.0.0.1:8000/api/v1/admin/imports/<id> -H "Authorization: Bearer <access_token>"
```

Путь указывается на **машине, где работает сервер**. Исходные файлы не меняются:
сервер копирует их в своё хранилище.

**Отдельные файлы** — *Коллекция → Загрузить файлы* (Ctrl+U), работает и с
другого компьютера.

**Конфликты.** Если файл — та же запись, что уже есть в библиотеке (тот же
исполнитель и название, длина в пределах 8 секунд), но сам файл другой, он не
импортируется молча, а ждёт вашего решения: *оставить старый* или *заменить
новым*. В окне конфликтов рядом видны качество, длина и размер обоих файлов;
сервер заранее советует «заменить» только для явно лучшей копии (lossless вместо
lossy или битрейт выше более чем на 5%). Есть кнопки для всех сразу. Замена
подменяет только сам файл, **лайки, плейлисты, историю прослушиваний и то, чему
волна научилась на этом треке, это не затрагивает**. Точная копия уже имеющегося
файла конфликтом не считается, это просто дубликат. Ожидающие решения файлы
хранятся в памяти сервера: после его перезапуска вопрос исчезает, а файл можно
импортировать заново.

### Удаление

Администратор удаляет трек в панели деталей (корзина) или клавишей Delete, с
подтверждением. Вместе с треком уходит файл с диска, а также опустевшие альбомы и
исполнители, из плейлистов он пропадает, а их итоги пересчитываются. Через API
есть и пакетное удаление: `POST /api/v1/tracks/bulk-delete`.

Windows не даёт удалить файл, который прямо сейчас играет. Такой файл остаётся на
диске лишним, и `POST /api/v1/admin/cleanup` его уберёт. Эта очистка нарочно ручная
и отказывается работать при пустом каталоге: иначе, пересоздав базу «с нуля», вы
дали бы ей приказ удалить всю фонотеку как ненужную.

### Клиент подробнее

Запуск — `run-client.bat`. Ключи:

```bat
run-client.bat --wave                        :: сразу включить волну
run-client.bat --server http://host:8000     :: другой сервер
run-client.bat --help                        :: остальное
```

Лог пишется в `%LOCALAPPDATA%\Wavelane\client.log` — у GUI-сборки на Windows нет
консоли, так что при любой непонятной проблеме смотреть надо туда.

### Тексты песен

Кнопка **Текст** в нижней панели открывает слова играющего трека поверх страницы.

- **Синхронизированный** текст идёт вместе с музыкой: поющаяся строка подсвечена и
  держится по центру. Если прокрутить колесом или перетащить, просмотр пять секунд
  ждёт и возвращается к строке сам (или кнопка «К текущей строке»). Клик по строке
  перематывает песню к ней.
- **Обычный** текст просто показывается и прокручивается.
- Если текста нет, так и написано.

Текст добавляет и правит только администратор: «Добавить текст» / «Править» в самом
окне текста. Вкладка «Текст» принимает обычный текст или LRC (`[01:23.45] строка`).
Вкладка «Синхронизация» проигрывает трек, а вы нажимаете Enter (или «Отметить») в
момент начала каждой строки; Backspace возвращает на шаг назад и перематывает
трек. Готовый результат хранится как LRC в поле `lyrics` трека, поэтому его
можно скопировать и править руками. Если в тегах файла уже был текст, он
подхватывается при импорте как обычный.

API: `GET /tracks/{id}/lyrics` (все), `PUT` и `DELETE` на том же пути (админ).

В списках после названия трека стоит значок: серый — есть обычный текст, синий —
текст синхронизирован. Для него трек приходит с полем `lyrics_kind`
(`none` / `plain` / `synced`).

### Персонализация

Настройки (шестерёнка слева внизу) → «Персонализация»:

- **Светящиеся пятна** фона страницы «Моя волна» можно выключить. Это самое дорогое,
  что рисует клиент: шейдер на видеокарте считается каждый кадр. Выключенный фон не
  загружается вовсе (в проверке на тестовой сборке нагрузка процесса упала с ~59% до
  ~12% одного ядра при выключенных пятнах и визуализаторе).
- **Визуализатор** под кнопками: столбики, волна, точки, кольцо вокруг кнопки
  воспроизведения или выкл. Если выключены и пятна, и визуализатор, страница
  ничего не анимирует.

### Windows и Discord

Что играет, видно за пределами окна. Настройки — шестерёнка в левом нижнем углу.

**Панель мультимедиа Windows** (громкость, экран блокировки, быстрые настройки)
работает сама, без настройки: обложка, название, исполнитель, полоса прогресса.
Медиа-клавиши клавиатуры и гарнитуры ставят на паузу, переключают трек и
перематывают. Это системный API (`SystemMediaTransportControls`), на других
системах эта часть просто не включается.

В панели приложение подписано «Wavelane»: при запуске клиент записывает своё имя
для Windows (запись в «Пуске» и в реестре под `HKCU\Software\Classes\AppUserModelId`).
Без этого панель показывает «Unknown app».

**Discord Rich Presence** («Слушает Wavelane», название, исполнитель, полоса
времени) настраивать не нужно: приложение в Discord общее, его Application ID
зашит в клиент (`DiscordPresence.cpp`). В настройках его можно только включить
или выключить.

Связь с Discord держит не сам клиент, а маленький помощник — тот же `wavelane.exe`,
запущенный с `--discord-relay` и не входящий в дерево процессов клиента. Когда
клиент закрывается как угодно (крестик, Alt+F4, «Снять задачу» в диспетчере),
помощник замечает, что связь оборвалась, убирает статус и сам завершается.
Иначе Discord ещё долго показывал бы «Слушает Wavelane».

Обложки треков Discord загружает со своей стороны, поэтому они появятся, только
если сервер виден из интернета (адрес берётся из настройки сервера клиента). С
сервером на этом же компьютере или в домашней сети вместо обложки показывается
лого, загруженное в приложение под именем `wavelane`.

Клиент сам ищет запущенный Discord и подключается к нему, как только тот появится;
если Discord закрыт, ничего не происходит.

### Android

Приложение для телефона собирается из тех же исходников: `client\build-android.bat`
делает подписанный `dist\Wavelane-android.apk`, а `client\build-android.bat install`
ещё и ставит его на телефон через `adb` (на телефоне должна быть включена отладка по USB).
Нужны Qt 6.8.3 для Android (arm64), NDK r26b, JDK 17 и Android SDK 34; всё лежит в
`E:\Wavelane\tools`. Ключ подписи `tools\android\wavelane.keystore` сохраните: обновить
установленное приложение можно только тем же ключом.

Внешний вид тот же, но раскладка своя (`MobileMain.qml`): вкладки «Поиск / Моя волна /
Коллекция» внизу, мини-плеер над ними, полный плеер и слова песни по нажатию. Чтобы
посмотреть её на компьютере, запустите клиент с `WAVELANE_MOBILE=1`. Значки на телефоне
берутся из встроенного шрифта Material Icons (шрифта Segoe там нет), а метки остаются
моноширинными благодаря встроенному Cascadia Mono.

Музыка играет при выключенном экране: для этого есть служба переднего плана с
уведомлением (кнопки «Назад / Пауза / Дальше», обложка, перемотка на экране блокировки).
Кнопка «Назад» на главном экране сворачивает приложение, а смахивание из списка
недавних закрывает его вместе с музыкой. Обычный цикл событий Qt на Android замирает,
как только окно уходит с экрана (и вместе с ним переход к следующему треку), поэтому у
главного потока свой цикл без этой остановки (`main.cpp`); а анализ звука для картинки и
анимации в это время отключаются, чтобы не тратить батарею.

Сервер по `http://` разрешён манифестом (`usesCleartextTraffic`), пока у него нет HTTPS.
С мобильного интернета нужен адрес, доступный из интернета; в домашней сети подойдёт
адрес вида `http://192.168.0.202:8768`.

### Сборка клиента

Нужны Qt 6.5+ с модулем Multimedia, CMake 3.21+ и компилятор C++20.

```bat
client\build.bat Release     :: или Debug
```

Пересобирать нужно только после изменений в `client\src` или `client\qml`.
Если клиент запущен, его надо закрыть — иначе компоновщик не сможет перезаписать
`wavelane.exe`.

`build.bat` жёстко указывает на Qt в `tools\Qt`, MSVC и pip-версии cmake/ninja,
чтобы сборка не зависела от `PATH`. При другом расположении Qt поправьте в нём
`QT_DIR` или соберите вручную:

```bash
cmake -S client -B client/build -G Ninja -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.3/gcc_64
cmake --build client/build --parallel
```

После первой сборки рядом с `wavelane.exe` нужно разложить библиотеки Qt —
один раз:

```bat
tools\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe --qmldir client\qml client\build\wavelane.exe
```

### ffmpeg — настоятельно рекомендуется

Без ffmpeg анализ опирается только на теги, и все треки без жанровых тегов
получают одинаковые характеристики — волне будет не на чем учиться. Укажите
путь в `.env`:

```ini
WAVELANE_FFMPEG_PATH=/usr/bin/ffmpeg
```

Проверить: `GET /health` вернёт `"dsp_analysis": true`.

## Как работает «Моя волна»

Каждый трек сводится к вектору из 10 нормированных характеристик — темп,
энергия, валентность, танцевальность, акустичность, инструментальность,
яркость, громкость, динамика, вокальность. Их извлекает
[`services/audio_analysis.py`](server/wavelane/services/audio_analysis.py):
темп — по автокорреляции огибающей атак, тональность и мажор/минор — по
корреляции хромы с профилями Крумхансль, остальное — из спектрограммы. Всё на
numpy, без тяжёлых ML-зависимостей.

Подбор идёт в четыре шага
([`wave/engine.py`](server/wavelane/wave/engine.py)):

1. **Контекст** — долгосрочный профиль вкуса, вектор текущей сессии, симпатии к
   жанрам и исполнителям, что играло недавно, что забанено.
2. **Пул кандидатов** — несколько независимых SQL-запросов с разных сторон:
   избранное, близкие исполнители, близкие жанры, хиты каталога, никогда не
   слышанное, случайное. Смешивание источников не даёт потоку скатиться в один
   кластер.
3. **Скоринг** — numpy по вектору звука плюс симпатии, популярность и штрафы
   ([`wave/scoring.py`](server/wavelane/wave/scoring.py)).
4. **Отбор с диверсификацией** — жадный проход с кулдауном на исполнителя и
   альбом и долей исследования, чтобы подборка не звучала как один альбом.

Несколько решений, которые стоит знать:

- **Настроение — это фильтр, а не слагаемое.** Обученный вектор вкуса даёт
  косинус около 0.95, и настроение как ещё одно взвешенное слагаемое всегда
  проигрывало: на запрос «бодрое» возвращалось то же спокойное избранное.
  Выбор настроения — указание, *какая* музыка допустима, а вкус уже решает
  порядок внутри допустимого.
- **Два горизонта обучения.** Долгосрочный профиль — скользящее среднее с
  потолком веса, вектор сессии меняется быстро. Поэтому один дизлайк заметно
  меняет следующие несколько треков, но не переписывает ваш вкус.
- **Дизлайк необратим.** Он не просто смещает вектор, а сохраняется как реакция,
  по которой жёстко фильтруется выборка — иначе трек возвращался бы на новом
  круге.
- **Жёсткие фильтры не ослабляются.** Если пул пуст (маленький каталог, узкий
  фильтр по языку), ослабляются только предпочтения. Забаненный исполнитель не
  вернётся никогда, даже если играть больше нечего.
- **Косинус считается от центра.** Все характеристики в 0..1 смотрят в одну
  сторону, поэтому сырой косинус близок к 1 даже для противоположных треков;
  вычитание нейтральной середины возвращает признаку различающую силу.
- **Жанровый тег разрешает октаву темпа.** Автокорреляция регулярно даёт ровно
  половину или двойной темп. Усреднять нельзя — середина между 66 и 132 это 99,
  музыкально бессмысленное значение. Вместо этого типичный темп жанра выбирает,
  какая октава правдоподобна; на демо-каталоге это подняло точность с 4/6 до 6/6.

Обычное прослушивание учит волну наравне с лайками: клиент отправляет
`POST /library/plays` с фактически прослушанным временем, и досушанное до конца
— сильный положительный сигнал, брошенное через четыре секунды — отрицательный.

## Структура

```
server/
  wavelane/
    models/      — SQLAlchemy 2 (19 таблиц), совместимо с SQLite и PostgreSQL
    schemas/     — DTO на Pydantic v2
    api/routers/ — auth, catalog, wave, library, playlists, upload, stream
    services/    — security, storage, ingest, audio_analysis, streaming
    wave/        — features, scoring, feedback, engine
  scripts/       — генератор демо-каталога
  tests/         — 153 теста
client/
  src/           — ядро на C++: ApiClient, Player, контроллеры
  qml/           — интерфейс
```

## Разработка

```bash
cd server
../.venv/Scripts/python.exe -m pytest -q        # 153 теста, ~30 с
../.venv/Scripts/python.exe -m ruff check .
```

Тесты герметичны: своя БД и своё хранилище на каждый тест, DSP-анализ отключён
(у него отдельные тесты на синтетическом сигнале), поэтому результат не зависит
от того, что стоит на машине.

### Иконка и логотип

Логотип — три волны без фона. Рисунок один на всё: `client/qml/Logo.qml` (в
интерфейсе) и `client/resources/make_icons.py` (иконка приложения) используют одну
геометрию и одни цвета. Поменяли рисунок — перегенерируйте файлы иконки:

```bash
.venv/Scripts/python.exe client/resources/make_icons.py
```

Скрипт пишет `wavelane.ico` (иконка самого `.exe`) и `wavelane-<размер>.png`
(иконка окна); при сборке они вшиваются автоматически.

## Переход на PostgreSQL

Код изначально совместим с PostgreSQL: JSON-поля разворачиваются в JSONB,
схема проверяется на обоих диалектах. Меняется одна строка:

```ini
WAVELANE_DATABASE_URL=postgresql+asyncpg://wavelane:пароль@localhost:5432/wavelane
```

Плюс `pip install -e ".[postgres]"`. На больших каталогах стоит заменить
генерацию пула кандидатов на индекс приближённого поиска соседей (pgvector),
всё остальное в движке останется как есть.
